# Development
before start 


mac-os
```
brew install gdal
```

linux

```
sudo apt-get install gdal-bin
```

For both platforms

```
pip install poetry
poetry install
```

For added new dependency
```
poetry add <dependency-name>
```

For remove some dependency
```
poetry remove <dependency-name>
```
